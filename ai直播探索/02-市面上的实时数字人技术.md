# 市面上的实时数字人技术（2026-10 调研）

结论：有，而且已经很多。Vidu S2 不是唯一，也不是最便宜的。主要有三类。

## 1. 国内数字人直播 SaaS（面向商家，开箱即用）

| 产品 | 特点（来自第三方横评，仅供参考） |
|---|---|
| 硅基智能 | 克隆快、门槛低、价格亲民，适合中小电商；大模型互动深度一般 |
| 百度智能云曦灵 | 大模型对话能力强，偏平台型，适合政企 |
| 商汤如影 | 画面质感好，偏高端品牌 |
| 腾讯智影 | 服务状态说法矛盾（有说 2025 年已关停），需要向官方核实 |

特点：多数需要先录一段真人视频来训练形象，走的是「话术脚本 + 弹幕问答」的带货模式，按年或按套餐收费。

## 2. 实时数字人 API（面向开发者，与 Vidu S2 同类）

| 产品 | 价格（美元/分钟，第三方汇总，2026 年中） | 说明 |
|---|---|---|
| HeyGen LiveAvatar | 约 0.09（只画脸）/ 约 0.18（全托管） | 也有「只画脸」和「全托管」两种模式 |
| Anam | 约 0.11–0.16 | 托管方案里较便宜 |
| Tavus | 约 0.31 | 偏贵，效果好 |
| Simli | 约 0.01–0.05（只画脸） | 最便宜的渲染层，其余要自己配 |
| D-ID Agents | 说法不一 | 大用量要谈企业版 |
| **Vidu S2** | 约 0.39–0.45（实时版）/ 约 0.26–0.30（组件版） | 国产，有中文生态，但单价偏高 |

注：Vidu 区间的低值按国内价（1 积分约 0.031 元，汇率约 7.1）换算，高值按国际价（1 积分 0.005 美元）计算。各家价格以官网为准。

## 3. 开源方案（自己部署，要显卡）

- **LiveTalking**（原 metahuman-stream）：串起语音识别、大模型、TTS 和数字人，支持 MuseTalk、wav2lip 等模型，可以 RTMP / WebRTC 推流，Apache-2.0 协议。wav2lip 在 3060 以上显卡能跑，MuseTalk 在 3080Ti 上约 45 fps（旧数据）。
- **MuseTalk**（腾讯音乐开源的口型驱动模型）
- **Duix**（硅基智能开源）、**OpenTalking** 等

特点：没有按分钟计费，但要买显卡或租 GPU，效果和稳定性要自己调。

## 怎么选

- 想最快开播、做带货：国内 SaaS。
- 想自己开发、做互动角色：API（HeyGen / Anam 便宜；Vidu 中文好、国内网络稳）。
- 想控制成本、长期跑：开源 + 自有 GPU。
- 不管哪种，在抖音都要遵守「真人实名、实时驱动」的规定。
