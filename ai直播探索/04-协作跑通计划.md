# 协作跑通计划（草案）

目标：用 Vidu S2 做一个合规的 AI 数字人直播间，在抖音上真正开播一次。

## 合规架构：「AI 副驾驶 + 真人主播」

```
抖音弹幕 ──► 控制台（我写的程序）──► 大模型 + 人设 → 起草回复
                    │
                    ▼
              真人确认 / 修改 / 自己说   ← 满足「真人实时驱动」
                    │
                    ▼
     Vidu S2（数字人画脸 + 口型）──► 窗口 ──► OBS / 直播伴侣 ──► 抖音
```

## 阶段

1. **阶段 0 · 账号与素材**：注册 Vidu，拿 API Key；在控制台试玩官方 demo；准备形象图、声音样本、人设。
2. **阶段 1 · 本地跑通数字人**：程序调用 Vidu S2，电脑上出现会说话的数字人窗口，手动输入文字就能让她说。
3. **阶段 2 · 接入大模型与审核台**：输入一条弹幕 → AI 起草回复 → 你点「发送」或改写 → 数字人说出来。
4. **阶段 3 · 接入真实弹幕**：先手动复制粘贴，再研究合规的自动采集方式。
5. **阶段 4 · 推流试播**：OBS 采集窗口，用小号或仅自己可见的方式试播，测延迟和成本。
6. **阶段 5 · 正式开播**：完成虚拟人注册和实名，按规范打 AI 标识，真人值守开播。

## 预算参考
- 调试阶段：先用赠送积分；实时版约 2.8 元/分钟，组件版约 1.9 元/分钟。
- 正式开播：每小时约 110–170 元（另加大模型和 TTS 费用，组件版需要）。
