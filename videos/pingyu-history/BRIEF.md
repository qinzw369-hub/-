## Intent

从史书中"平舆"之名首次出现（前225年，《史记》"李信攻平舆"）讲起，七幕加尾声：
秦灭楚之战 → 沈国与柏举之战 → 东汉汝南郡治与许氏三世三公 → 月旦评 → 陈蕃 →
废县千年与1951年复县 → 1975年大水与今日平舆 → 尾声。纪录片腔，沉稳。
解说文案已由用户认可（"故事还可以"）。

## Customizations

- 地图是贯穿全片的主线：古卷舆图风格的矢量地图（行政区与河流），而非实时卫星瓦片。
- 历史人物无真实画像：用剪影/水墨处理，标注"艺术想象"。
- 古籍原文以竖排书法字幕呈现。

## Notes

- 4K 横屏（3840×2160）交付；故事板与预览用 1920×1080。
- 网络受限：只能访问 npm 与 GitHub。字体从 google/fonts 下载后按用字裁剪子集，内嵌项目。
- 文案中标记"需核实"的史实（废县时间、1951复县、许氏三公官职等）发布前须对照《平舆县志》。
- 用户提出的流程：先出 3 个故事板风格变体 → 选定后每幕一张静态帧 → 再做动画；用导演式笔记迭代。
